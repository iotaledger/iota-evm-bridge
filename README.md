# IOTA EVM Bridge


Build the sdk:
```sh
pnpm sdk build
```

Run the bridge app:
```sh
pnpm app dev
```

Check eslint and formatting:

```sh
pnpm run lint
```

Fix eslint and formatting:

```sh
pnpm run lint:fix
```
